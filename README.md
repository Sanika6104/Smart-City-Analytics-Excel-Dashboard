# 🏙️ Smart City Analytics Dashboard

## 📊 Project Overview

The Smart City Analytics Dashboard is an interactive Microsoft Excel dashboard designed to analyze urban performance, environmental conditions, mobility, and sustainability indicators.

The project transforms raw smart-city data into meaningful insights using Excel's data analysis and visualization features.

---

## 🎯 Objectives

- Analyze air quality across different cities
- Understand the relationship between AQI and traffic
- Analyze environmental and sustainability indicators
- Compare city-wise AQI performance
- Analyze population distribution across zones
- Study monthly AQI trends
- Create an interactive dashboard for data exploration

---

## 📌 Key Metrics

- Average AQI: 155.9
- Average Traffic Index: 75.7
- Green Cover: 20.8%
- Electricity Consumption: 15.96M
- Water Consumption: 1.06M
- Waste Generated: 43.9K

---

## 🔍 Dashboard Analysis

The dashboard includes:

- AQI vs Traffic Index
- Average AQI by City
- AQI Distribution by City
- Monthly AQI Trend
- Population Distribution by Zone
- AQI by City across India
- Environmental indicators
- Interactive City and Zone filters
- Time Period filtering
